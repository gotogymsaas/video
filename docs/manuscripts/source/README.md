# Fuentes de los cinco manuscritos

Compila desde esta carpeta con pdfLaTeX, dos pasadas por documento. Se requieren los paquetes declarados en preamble.tex y las figuras de figures/. Los PDF de entrega están en la carpeta superior; no es necesario LaTeX para usar el sistema.

Ejemplo:

```bash
pdflatex -interaction=nonstopmode 01_Fundamentos_QAF_Audiovisual.tex
pdflatex -interaction=nonstopmode 01_Fundamentos_QAF_Audiovisual.tex
```
