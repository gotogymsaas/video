# Implementación y falsación de los 42 manuscritos

Fuente original: QAF_Cinema_Programa_Integral_42_Manuscritos.pdf (36 papers técnicos y seis aprendizajes acumulativos).

`registry.json` registra los **42 identificadores** con referencias a código parcial existente y dependencias. Ningún artículo se marca validado científicamente por existir una función: cada uno exige implementar la ecuación completa, ejecutar pruebas reales con derechos, baseline clásico del mismo presupuesto, métricas OOD y réplica independiente.

Ejecutar `python -m qaf_video.generative_research.audit_42 .`. Un resultado de enlaces de código significa proximidad técnica, **no implementación íntegra ni superioridad matemática QAF**.

Brechas críticas: movimiento neuronal humano entrenado, geometría 6DoF, campos neurales 3D, oclusión de dedos sobre pantalla seguida, iluminación físicamente coherente y benchmarking profesional. El sistema híbrido existente renderiza prototipos y puede componer videos externos, sin sustituir dichas capacidades.

El volumen original está disponible como archivo de la conversación, no publicado como PDF binario en este repositorio.
